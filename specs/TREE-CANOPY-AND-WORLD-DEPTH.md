# 树冠与世界纵深优化

状态：第一轮实现和浏览器检查完成，最终视觉签收待用户查看。2026-09-05 用户授权本轮直接实施场景优化。

## 目标与边界

修复绕桌旋转时树冠消失，改善树冠厚度，补出中远景空间延伸感。
继续复用 Bruno 原场景、材质、昼夜、风、水和单 Canvas。
本轮不变更桌状态、REST/WS、桌桥位置、首页分工和最终 Agent 资产。

## 已核实原因

- Foliage 的叶片平面全部平行，仅在初始化朝向默认相机；默认 FrontSide 在背面剔除。
- Trees 启用 seeThrough，屏幕中心 distanceFade 会将叶冠 alpha 降至裁切阈值以下。
- mesh 已设置 frustumCulled=false，不能把本问题归因于视锥剔除。

## 实施

1. 树冠关闭屏幕中心裁空；树叶改为双面，叶片分布到多个方向，保留原 SDF 纹理和光照。
2. 树叶簇从 80 增至 112 片（40%），灌木数量保持原值；保持实例化，不增加每树 draw call。
3. 增加远处连续起伏地形轮廓，使用确定性几何、原场景光照和雾色，无背景图片、无第二 renderer。
4. 检查默认、侧面、背面、低角度及缩放；记录真实浏览器结果与构建结果。

## 验收

- 相机绕桌一周不出现整片叶冠背面消失或中心裁空。
- 叶簇有方向层次，保留透光空隙；遮挡桌面的树冠问题按实际截图记录，不重新使用全屏裁空。
- 远景有连续地形轮廓，近处桥、水和桌保持原布局。
- 无 shader 错误、单 Canvas；测试结果与视觉签收分开记录。
- 用户最终审美签收待实际观看，不以构建成功代替。

### 构图目标

- 山侧使用“林地前坡 → 雾中山脚 → 偏位主峰 → 两段较低雪肩 → 天空缺口”的层次。主峰放在桌区左后方或瀑布遗迹后方，不与桌中心、樱花树干和主要按钮重叠。
- 主峰只占山侧约三分之一视野；两侧山肩逐渐降入林线。默认 1440×900、34 米机位下，最高峰约占画面高度 18%–24%，至少保留 35% 连续天空。
- 海侧保持完整开放，不允许山体绕到海平线。旋转到海侧时只看到水面、远岸薄雾和少量孤立植被。
- 桌、樱花、瀑布遗迹和吧台仍是近景叙事中心；雪山负责建立世界边界，不抢走第一视觉焦点。

### 山体重建

- 不再直接把完整矩形 HGT 区块作为一个远景对象。离线生成时按峰群裁成三个自然地形块：主峰、左山肩、右山肩；每块使用椭圆/地形谷线遮罩下沉边缘，避免直线裁切和连续等高锯齿。
- 优先从 Eiger–Mönch–Jungfrau 数据中选择有明确高低关系的峰群；Matterhorn 作为偏位单峰备选。先输出无材质灰模截图，通过轮廓后再做雪面。
- 主峰保留约 60k–90k 三角形，山肩合计约 30k–50k；每块都有 20%–30% 远距档位。LOD 以真实相机距离和屏幕占比验收，切换时不能出现轮廓跳变。
- 山体整体后移至距桌约 135–175 米；根据实际轮廓单独调整 X/Z 比例，不再通过夸张 Y 比例制造高山感。山脚必须低于林线并被前坡和高度雾遮住。

### 材质与云雾

- 岩面采用蓝灰、暖灰两层，按坡向、曲率和低频噪声形成大块阴阳坡；Snow 02 只提供微观变化，不能把山体整体涂成白色。
- 雪线集中在上部约 30%–40%，沿沟谷向下延伸，在迎风缓坡积雪、陡壁露岩。改用三平面投射，避免当前 XZ 投射在陡壁上拉伸。
- 云拆为两到三个窄体积：山腰云带、主峰薄云和山谷低雾。云之间必须留空，边缘缓慢变化；不再使用覆盖整片山墙的单个大盒子。
- 白天雪面保持暖白并接受 Bruno 有色阴影；夜间是低亮度月蓝，峰顶不能发光。远山对比度低于樱花和桌区。

### 执行顺序

1. 暂时将默认山体切回旧远景或隐藏新 DEM，保留 `?alpine=eiger-wall` 作为问题对照。
2. 生成三块灰模，固定五个验收机位，先只比较轮廓、位置、天空留白和海侧开口。
3. 选定灰模后接入岩面、三平面雪材质与山脚雾。
4. 最后放置三个局部云体，校准白天、夜间和自动昼夜。
5. 验证 1440×900、390×844、34 米远景、16.8 米桌边、海侧、山侧和自由拖拽；记录单 Canvas、控制台和帧时间。

### 视觉验收门槛

- 第一眼读到一座主峰及其山肩，而不是重复锯齿或连续背景墙。
- 山脚没有矩形边、垂直断面或漂浮；林地到雪山至少经过低坡和雾两层过渡。
- 雪面能看出岩壁、雪沟和受光面，白天与夜间均不呈纯白/纯蓝发光体。
- 默认机位桌区仍是视觉中心；山体不遮桥、瀑布遗迹、樱花树冠主体和产品操作区。
- 海侧至少 120° 视角范围内没有雪山侵入。
