# 组一桌前端融合 — 当前交接（2026-09-02）

## 一句话现状

产品主仓已经把“桌海入口 → 桌边预览 → 桌内 3D → 实时讨论 → 历史回放 → 收桌卡”串成一条前后端链路。桌内只保留圆桌场景与观察交互：不包含载具、驾驶、游戏角色控制或第三方品牌展示。

## 运行方式

| 服务 | 地址 | 用途 |
|---|---|---|
| Vite 前端 | `http://localhost:5175`（端口被占用时会顺延） | React 入口、桌海、HUD、弹层 |
| FastAPI 后端 | `http://localhost:8000` | REST 投影、WS 实时讨论、回放和收桌产物 |

开发服务器代理已经写入 `vite.config.ts`，`/tables`、`/matches`、`/participants`、`/personal-context`、`/ws` 等请求会转发到后端 8000。

## 前端结构

- `src/App.tsx`：阶段状态、桌选择、入席、收桌和世界级 HUD。
- `src/TableSea.tsx`：桌海入口；本地种子会被 `GET /tables/discovery` 的后端投影补充。
- `src/Lobby.tsx`：桌边预览；显示成员、空席、当前子问题和 `POST /matches/preview` 的匹配理由。
- `src/ValleyScene.tsx` + `src/Diorama.tsx`：当前桌内主视觉；保留湖面、山谷、码头、木屋、树林、花草、圆桌和人物构图。
- `src/App.tsx`：桌内通过独立 R3F Canvas 挂载主视觉，后端状态和 DOM HUD 叠加在其上；不再挂载程序化的简化桌景。
- `src/ValleyScene.tsx` 的 `CameraRig`：鼠标左键拖拽改变环绕视角；相机变化不会修改世界状态。
- `src/TableWorld.tsx` 与 `src/table-engine/`：保留的实验性桌面运行时，当前不作为主视觉入口，避免误把低保真 fallback 当成产品场景。
- `src/live/api.ts`：REST 客户端与超时/错误处理。
- `src/live/backend.ts`：建桌、真人入席、WS 主持动作、发言、请求引导、收桌和回放桥接。
- `src/live/DiscussionPanel.tsx`：只读讨论历史弹层，回放接口失败时保留已收到的实时表达。

## 后端对接映射

| 后端能力 | 前端入口 |
|---|---|
| `GET /tables/discovery` | 桌海缺口和桌状态 |
| `GET /tables/:id/lobby` | 桌边成员、空席、子问题 |
| `POST /matches/preview` | “为什么想到你” |
| `POST /tables` | 第一次进入时建桌兜底 |
| `POST /tables/:id/participants` | 真人入席 |
| `POST /tables/:id/participants/:pid/consent` | 资料公开授权 |
| `WS /ws/tables/:id` | 表达、主持动作、状态变化、收桌卡 |
| `GET /tables/:id/replay` | 对话历史弹层 |
| `request_nudge` / `request_close` | 主持人递话 / 收桌 |
